# Graduation Letter

Thiệp mời tốt nghiệp dạng static site, có thể deploy trực tiếp lên GitHub Pages.

## Chỉnh sửa nhanh

- Nội dung ngày, địa điểm, dress code: sửa trong `index.html`.
- Email nhận xác nhận: tìm `your-email@example.com` trong `index.html` và thay bằng email thật.
- Màu sắc, font và responsive layout: sửa trong `style.css`.
- Nhạc nền được tạo bằng Web Audio API trong `script.js`, không cần thêm file audio.

## Deploy GitHub Pages

1. Tạo repository mới trên GitHub.
2. Upload `index.html`, `style.css`, `script.js` và `README.md`.
3. Vào **Settings > Pages**, chọn branch `main` và thư mục `/ (root)`.
4. Mở đường dẫn GitHub Pages được cung cấp.
